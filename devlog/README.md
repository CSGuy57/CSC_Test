# Devlog

Two kinds of file live here.

- `sprint-NN.md` — your daily standup journal for that sprint. Three lines per class day.
- Retros live in the Sprint issue on GitHub, not here. One place, not two.

Copy `_TEMPLATE-sprint.md` at the start of each sprint. Commit it daily.

It takes ninety seconds. It is the single best predictor of whether a capstone finishes,
mostly because writing "blocked" on a Tuesday is how you get help on a Tuesday instead of
losing a week.
